# Simple React Task List

A minimal React app built with Vite.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
```
Output goes to the `dist` folder.

## Deploy on Netlify
- Build command: `npm run build`
- Publish directory: `dist`
(Already set in `netlify.toml`)
